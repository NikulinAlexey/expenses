# Учёт трат

Откройте `index.html` в браузере — всё работает без сервера и установки.

- Данные хранятся в localStorage этого браузера (на этом устройстве и в этом адресе).
- Кнопка «Скачать всё (JSON)» — полная резервная копия. Делайте её регулярно.
- «Загрузить из файла» — восстановление/перенос на другое устройство (дубли пропускаются).
- «CSV для Excel» — таблица для Excel/Google Таблиц.
- Категории — массив `CATS` в начале `app.js`.
- Подключение сервера: заменить методы `load`/`save` в объекте `Store` в `app.js`.
