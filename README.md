# Контроль трат

Небольшой сайт для учёта личных расходов на чистом HTML/CSS/JavaScript.

## Возможности

- добавление траты: вещь, категория, сумма, дата;
- хранение данных в `localStorage` браузера;
- сводка за текущий месяц;
- таблица расходов по месяцам;
- изменение расходов относительно предыдущего месяца;
- анализ расходов по категориям;
- график общей динамики за последние месяцы;
- история всех расходов с фильтром по месяцу;
- удаление записи.

## Запуск

Никакой сборки не требуется.

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Данные сохраняются только в браузере на конкретном устройстве. Базы данных и синхронизации между устройствами пока нет.

## Структура

- `index.html` — разметка;
- `style.css` — дизайн;
- `app.js` — вся логика и работа с данными.
